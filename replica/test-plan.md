# Test plan

Запуск: `npx playwright test`. Если браузер не скачан: `CHROMIUM_PATH=<путь к chrome> npx playwright test`.
Сервер стартует сам на :3100: Telegram подменён (`e2e/mock-telegram.js`), лимиты выключены (`NO_RATE_LIMIT`).
Каждый UI-тест падает на ошибке в консоли или ответе 5xx. На каталоге, товаре, корзине и в админке — axe-проверка: без serious/critical.
Проекты: desktop 1440 и mobile 390.

Вручную (после настройки env на проде):
- [ ] заказ на проде приходит владельцу в Telegram;
- [ ] Start по кнопке → шаблон с реквизитами; другой ник → отказ;
- [ ] скриншот в бота пересылается владельцу;
- [ ] загрузка фото с телефона в админке, товар появляется в каталоге ≤1 мин;
- [ ] «Нет в наличии» блокирует кнопку и заказ.

Шаблон бота, проверка ника и пересылка проверены вручную с подменой Telegram (см. историю сессии).
