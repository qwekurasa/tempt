# Recon: yeezy.com → tempt

Дата: 2026-10-19. Источник: публичные страницы yeezy.com, просмотр вручную в браузере.
Код, бандлы, сетевые запросы, изображения и тексты оригинала не сохранялись и не используются.

## Скоуп

- Платформа: веб (desktop + mobile).
- Срез: витрина — каталог → товар → выбор размера → корзина/оформление.
- Для кого: магазин tempt (товары из Китая, заказы через Telegram).
- Параметры tempt, которые переопределяют оригинал:
  - нет деления на мужское/женское (в оригинале переключатель MALE/FEMALE);
  - категории по брендам;
  - оплата не на сайте: заказ уходит в Telegram, реквизиты присылает бот;
  - доставка до ПВЗ Ozon / Яндекс / СДЭК вместо адреса и карты;
  - админка для добавления товаров.

## Флоу

```
F01 Покупатель выбирает и покупает вещь
    S01 → S02 → «+» → S03 выбрать размер → сумка → S05 заполнить → оплатить
    клики на happy path: товар 1, «+» 1, размер 1, сумка 1, форма + оплата ≈ 2 → ~6
    edge: нет размера (restock), пустая корзина, неверный адрес

F02 Покупатель смотрит описание
    S02 → «+» → S03 → INFORMATION → S04

F03 Покупатель проверяет заказ
    футер → S06 → ввести email/номер/индекс → статус

F04 Смена плотности каталога
    S01 «+» → 3 колонки → «‹» → 6 колонок
```

          evidence: S05, S06; confidence: medium

У tempt вместо `gender` — `brand`, вместо email/адреса/карты — ФИО, Telegram, телефон, служба ПВЗ, адрес ПВЗ; оплата вне сайта.

## Не клонируется

- Бренд, логотип, названия и артикулы товаров, фото, тексты описаний — собственность оригинала.
- Оплата картой на сайте — у tempt оплата по реквизитам через бота.
- Налоги, промокоды, подписка на рассылку, cookie-баннер с маркетинговыми cookie — не нужны tempt.
- Автодополнение адреса — требует платного геосервиса.
- Деление MALE/FEMALE — исключено по требованию.

## Размер

9 экранов, 4 флоу, 3 сущности. Сложные части:
1. Выбор размера карусель-панелью внутри оверлея товара.
2. Переключение плотности сетки с сохранением позиции прокрутки.
3. Единая страница корзины и оформления с адаптивом (на мобиле сводка сверху).

Оценка: **S** — бэкенд, корзина, заказ в Telegram и админка у tempt уже есть. Остаётся перестроить фронтенд под паттерны оригинала.
