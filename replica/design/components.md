# Компоненты tempt

Токены — `tokens.json`, в коде — `:root` в `public/style.css`.
Иконки и шрифты оригинала не используются: системные Helvetica/Arial и системный моноширинный.

Фокус на всех интерактивных элементах: `:focus-visible` — обводка 2px `accent`, отступ 2px.

**Шапка**
- **Варианты:** каталог/товар — «Каталог» слева, логотип по центру, «Корзина (n)» справа. В корзине шапки нет, вместо неё «←» и счётчик.
- **Токены:** высота `layout.header`, текст `sm`, фон `bg`.
- **a11y:** ссылки `<a>`, у «←» есть `aria-label`.
- **Экраны:** S01, S02, S05.

**Карточка товара**
- **Состояния:** обычная; hover — увеличение фото на 4%; без фото — пустая плашка.
- **Токены:** фон `surface`, текст `caption`, фото contain с полями 14%.
- **a11y:** вся карточка — `<a>`, название и цена текстом.
- **Экраны:** S01.

**Фильтры**
- **Варианты:** desktop — колонка `layout.sidebar`; mobile — скрыты, открываются кнопкой «Фильтры».
- **Состояния:** выбран / не выбран; «Сбросить».
- **Токены:** `xs`, чекбокс с `accent-color: accent`.
- **a11y:** нативные `<input type=checkbox>` внутри `<label>`.
- **Экраны:** S01.

**Сортировка**
- Нативный `<select>` без рамки, `xs`.
- **Экраны:** S01.

**Пагинация**
- **Состояния:** текущая (фон `surface`), disabled для ‹/› на краях. Показывает 1, последнюю и ±1 от текущей с «…».
- **Экраны:** S01.

**Галерея**
- Горизонтальный scroll-snap, точки-индикаторы (активная длиннее, `text-muted`). Точек нет при одном фото.
- **a11y:** свайп и прокрутка, точки — `<button>`.
- **Экраны:** S02.

**Плашка покупки**
- **Варианты:** с размерами / без размеров.
- **Состояния:** «Выберите размер» (disabled), «В корзину», «Добавлено ✓» на 1.5 с.
- **Токены:** фон `accent`, текст `on-accent`, радиус `pill`.
- **Экраны:** S02, S03.

**Секция характеристик**
- Заголовок `base` и текст `base` с переносами строк, разделитель — 1px `border`.
- **Экраны:** S02, S04.

**Поле ввода (оформление)**
- **Токены:** рамка 1px `accent`, радиус `none`, высота ≥48, плейсхолдер `text-muted` капсом.
- **Состояния:** focus — двойная рамка; invalid — сообщение `danger` в `#err`.
- **a11y:** `<label>` вокруг поля, autocomplete для имени и телефона.
- **Экраны:** S05.

**Выбор доставки**
- **Состояния:** не выбран — рамка `accent`; выбран — фон `accent`, текст `on-accent`, квадрат с галочкой; focus-visible — обводка.
- **a11y:** нативные radio, скрытые визуально, но доступные с клавиатуры.
- **Экраны:** S05.

**Строка корзины**
- Фото 64px, название, размер `text-muted`, количество −/+ (удаление при 0), сумма.
- **Экраны:** S05.

**Кнопка основная**
- **Варианты:** `.co-btn` — квадратная, моно-капс; `.btn` — pill, в админке.
- **Состояния:** disabled — opacity .3/.35.
- **Токены:** фон `accent`, текст `on-accent`.
- **Экраны:** S05, админка.

**Пустые состояния**
- Каталог: «Ничего не найдено».
- Корзина: «Корзина пуста», кнопка оформления неактивна.
- Админка: пустой список.
