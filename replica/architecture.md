# Architecture: tempt

Основа: `replica/recon.md`, `replica/features.csv`. Стек уже есть, его и оставляем.

## Стек

| слой | выбор | почему |
| --- | --- | --- |
| веб | статичные HTML/CSS/JS в `public/`, роутинг по hash | каталог небольшой, сборка не нужна, мгновенная загрузка |
| сервер | Express 5 (`server.js`) как функция Vercel | 1 файл, все роуты рядом |
| данные | Vercel Blob: `products.json`, `orders/<id>.json` | товаров десятки–сотни, БД избыточна; бесплатно в Hobby |
| файлы | Vercel Blob `images/` | фото сжимаются в браузере до 1600px |
| авторизация | пароль админа из env + HMAC-кука на 7 дней | один пользователь |
| заказы | Telegram Bot API (sendMessage, webhook) | заказы и общение с клиентами уже в Telegram |
| оплата | вне сайта, по реквизитам из бота | нет эквайринга и договора |
| хостинг | Vercel, автодеплой из GitHub `qwekurasa/tempt` | уже настроено |

Postgres не нужен, пока: товаров < ~2000, один админ, не нужны поиск и отчёты по заказам. При росте — Neon + Drizzle, перенос `products.json` → таблица `products`.

## Данные

```
products.json  (массив, новые сверху)
  id          uuid
  name        string ≤120
  brand       string ≤60, UPPERCASE
  color       string ≤60, UPPERCASE, опционально
  price       integer, рубли (> 0)
  sizes       string[]
  soldOut     boolean            ← добавить (матрица: «нет в наличии»)
  description string
  images      string[] ≤10, URL Blob или /demo/*.svg
  createdAt   ms

orders/<ID>.json  (ID — 12 hex, случайный, неугадываемый)
  id, name, tg, lines[], total
```

Правила доступа (в `server.js`, одна проверка на роут):
- `products.json` — чтение всем, запись только `auth`.
- `orders/*` — публичный Blob по неугадываемому ID. Бот отдаёт заказ только тому, чей @username совпадает с указанным в заказе.
- Телефон и адрес в `orders/*` не пишутся, они уходят только владельцу в Telegram.

Цены в рублях целым числом. Валюта одна.

## API

| метод путь | что делает | кто | вход | выход | флоу |
| --- | --- | --- | --- | --- | --- |
| GET /api/products | каталог (`?fresh` — в обход CDN для админа) | все | — | Product[] | F01 |
| POST /api/order | проверка, пересчёт цены, сообщение владельцу, сохранение заказа | все, лимит 5 за 10 мин с IP | ФИО, tg, телефон, служба, адрес, items, согласие | {id, bot} | F01 |
| POST /api/tg-webhook | /start ID → шаблон с реквизитами; остальное → пересылка владельцу | Telegram (secret_token) | Update | 200 | F01 |
| POST /api/login, /api/logout, GET /api/me | вход в админку | все / админ | пароль | кука | админ |
| POST /api/upload | фото в Blob | админ | image/* ≤4 МБ | {url} | админ |
| POST, PUT, DELETE /api/products/:id | CRUD товаров | админ | Product | Product | админ |
| POST /api/tg-setup | setWebhook | админ | — | {bot} | админ |

Входящие вебхуки: только Telegram. Фоновых задач нет.

## Где может укусить

- **Кэш CDN 60 с** — покупатель видит изменения через ≤1 мин. Админка и запись читают `?fresh`.
- **Гонка записей `products.json`** — два одновременных сохранения из разных вкладок: последнее побеждает. Админ один, приемлемо.
- **Повторы вебхука** — Telegram повторяет при не-200. Всегда отвечаем 200, ошибки только логируем.
- **Лимиты в памяти** — счётчик на каждый инстанс функции, защита слабая. При спаме заказов — Vercel Firewall rate limit.
- **Лимит тела запроса 4.5 МБ** — фото грузятся по одному и сжимаются в браузере.
- **Квота Blob Hobby**: 2000 advanced-операций/мес (put, del). Чтение каталога через CDN их не тратит.
- **152-ФЗ** — сайт собирает ФИО, телефон и адрес. Нужны политика обработки ПД и согласие в форме заказа.

## Порядок сборки

1. **Вертикальный срез** — готов: каталог → товар → корзина → заказ в Telegram → бот.
2. **Must** — готово, кроме полировки панели размеров (S03).
3. **Should**:
   - юр. страницы и согласие на обработку ПД (S09, S05);
   - раскрываемое описание (S04);
   - моноширинная типографика на всём сайте — по решению design.
4. **Could**:
   - «нет в наличии» (`soldOut`, S02/S03, админка);
   - размерная сетка;
   - переключатель плотности сетки 3/6 (S01);
   - статус заказа (S06) — не нужен: статус клиент узнаёт в боте.
5. **Fixes** — после `/replica-entrepreneur`.
