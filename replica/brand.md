# Brand: TEMPT

## Имя

Имя выбрано вами — **TEMPT** («соблазнять»). 20 кандидатов не генерировал.

**По фильтрам:**
- **Сходство с оригиналом.** Нет ни по звучанию, ни по смыслу.
- **Простота.** Короткое, пишется на слух.
- **Значение в больших языках.** В английском — «искушать», в русском лишних смыслов нет.
- **Угол из `fixes.md`.** Имя с ним не спорит.

**Риск:** это обычное английское слово, такие слова часто уже зарегистрированы как знаки в классе 25 (одежда, обувь). Поиск 2026-10-19 по запросу «TEMPT brand clothing store trademark» вернул существующие знаки со словом TEMPT в США (например, [TEMPT ME](https://trademark.justia.com/868/49/tempt-86849178.html)). Их класс и статус не проверялись.

| проверка | где | результат |
| --- | --- | --- |
| Россия (главное для вас) | fips.ru — открытые реестры, классы 25 и 35 | to run |
| ЕС | TMview | to run |
| США | tmsearch.uspto.gov, кл. 25/35 | to run, есть похожие записи (см. выше) |
| мировая | WIPO Global Brand Database | to run |
| домен | tempt.ru, tempt.store, tempt.shop — у регистратора | to run |
| Telegram | @tempt…: канал и бот | to run |
| Instagram, TikTok | точное имя | to run |
| веб | «tempt одежда», «tempt магазин» | to run |

Это предварительный скрининг. Если планируете вкладываться в имя (вывеска, реклама), сначала нужен поиск у патентного поверенного.

## Палитра

Чёрный, белый и тёплые серые. Роли и значения — в `design/tokens.json`. Контраст: 0 ошибок AA, 12 пар.

У оригинала тоже ч/б, но это не фирменный цвет, а норма для жанра. Узнаваемость tempt держится на тёплых серых (`surface #f6f6f5`, `surface-soft #f2f1ef`) и моно-капсе на оформлении. Своего акцентного цвета нет. Если понадобится, берите одну тёплую ноту для ссылок и бейджей и прогоните через `contrast.py`.

## Бриф логотипа

- **Идея:** «соблазн» без картинок — сдержанный wordmark с одной деталью-«крючком». Например, удлинённая перекладина T, которая ведёт взгляд к следующей букве.
- **Тип:** wordmark TEMPT и монограмма T для мелких размеров. Сейчас стоит временный favicon: белая T на чёрном.
- **Должен работать** в 16px (favicon) и 1024px (аватар канала и бота в Telegram).
- **Отдать:**
  - SVG wordmark и SVG монограмму;
  - PNG 1024×1024 без прозрачности — аватарки Telegram;
  - favicon 32/180/512;
  - картинку для превью ссылок 1200×630.
- **Нельзя:** узкий капс-гротеск с широкой разрядкой в духе оригинала, его формы и пары цветов. Положить черновики рядом с маркой оригинала и сравнить.

## Голос

Три слова:
- **Прямой** — но не грубый.
- **Спокойный** — но не холодный.
- **Конкретный** — но не канцелярский.

| делаем | не делаем |
| --- | --- |
| «Срок доставки: 14–21 день» | «Скоро доставим!» |
| «Мы свяжемся с вами в Telegram» | «Ваш запрос передан команде» |
| «Корзина пуста» + куда идти дальше | «Упс! Тут ничего нет 😢» |
| «Нет в наличии» | «SOLD OUT 🔥» |
| ошибка говорит, что исправить: «Некорректный номер телефона» | «Что-то пошло не так» |

**Самые видимые строки** уже в этом голосе и написаны с нуля. Проверено:
- кнопки: «В корзину», «Выберите размер», «Добавлено ✓», «Оформить заказ», «Получить реквизиты в Telegram»;
- пустые состояния: «Корзина пуста» (добавлена ссылка «Перейти в каталог»), «Ничего не найдено»;
- экран после заказа: «Заказ #… оформлен», «Мы свяжемся с вами в Telegram…»;
- сообщения бота: шаблон с реквизитами, «Заказ #ID: статус».

Одна строка выбивается: «Ошибка сервера». Она нейтральна и показывается редко, оставлена как есть.
