## Сервисы

- **База** — Vercel Blob `tempt-blob`, Франкфурт. Отдельный dev-проект не создавался: локально сайт работает без Blob, на демо-данных. Автобэкапов нет — скачивайте `products.json` из Storage после крупных правок.
- **Stripe, OAuth, email** — не используются.

## Домен (когда купите)

Покупаете у любого регистратора вы. Затем Vercel → Settings → Domains → Add, и в DNS:

| запись | имя | значение |
| --- | --- | --- |
| A | @ | IP, который покажет Vercel в настройках домена |
| CNAME | www | `cname.vercel-dns.com` |
| TXT | как попросит Vercel | значение верификации, если попросит |

Основной — apex (`tempt.ru`), `www` редиректит на него. HTTPS Vercel выпускает сам. После смены домена снова нажмите «Подключить бота»: вебхук привязывается к домену, с которого нажали.

Почта на домене не нужна: письма не отправляются.

## Наблюдение

- Ошибки: Vercel → Logs (Runtime). Там видны `Telegram:`, `webhook:`, `order save:`.
- Аналитика: Vercel Web Analytics — бесплатно и без cookie, включается в проекте.
- Аптайм: любой бесплатный монитор на `/api/products` раз в 5 минут.
- Первая неделя: каждый заказ сверять с сообщением в Telegram. Проверить, что приходит «клиент получил реквизиты».

## Осталось сделать вам

1. Vercel → Environment Variables → добавить `PAYMENT_DETAILS` с текстом реквизитов, затем Redeploy.
2. `/admin` → «Подключить бота».
3. Вписать реквизиты оператора и ник для связи в `public/privacy.html` — или прислать их мне.
4. Сделать тестовый заказ на себя с телефона: сайт → бот → `/status ID тест`.
